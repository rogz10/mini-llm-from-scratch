# Mini GPT from Scratch

Implémentation d’un modèle de langage de type GPT en Python avec PyTorch, conçu pour être entraîné à petite échelle.

Le projet couvre la tokenisation, l’architecture Transformer à attention causale, l’entraînement à la prédiction du prochain token et la génération de texte.

Il intégrera la visualisation des embeddings, l’évaluation des connaissances du modèle (*knowledge probing*) et des expériences de fine-tuning supervisé (*SFT*) pour apprendre à répondre, à s’abstenir et à utiliser des outils.

**Statut : en développement.**
